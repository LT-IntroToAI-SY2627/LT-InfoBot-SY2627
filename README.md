# Lane Tech Info Bot 🤖
**Built by the Introduction to AI class | Lane Tech College Prep | 2026-2027**

---

## What Is This?

The Lane Tech Info Bot is a class-built AI-powered chatbot that answers questions about Lane Tech College Prep. Students, staff, and visitors can ask it anything about the school — schedules, clubs, events, sports, and more — and get a helpful response in plain English.

This app is being built from scratch by students in Mr. Berg's Introduction to AI course. Every unit, students learn a new Python concept and contribute a real piece of code to this repository. By the end of the year it will be a fully functioning, AI-powered application that the Lane Tech community can actually use.

---

## What It Will Do

By the end of the year the Info Bot will be able to:

- Greet users and respond to basic questions about the school
- Match user questions to the right responses using pattern matching logic
- Store and retrieve real Lane Tech data — clubs, schedules, events
- Handle questions it was never explicitly programmed to answer using the Gemini AI API
- Learn and improve as more data and features are added

---

## How It's Being Built

This project grows unit by unit throughout the year:

| Unit | What Gets Added |
|---|---|
| Unit 1 — Python Basics | Project setup, greetings, basic input/output |
| Unit 2 — Functions & Logic | Question routing and pattern matching |
| Unit 3 — OOP | Core classes: Chatbot, User, Club, Event |
| Unit 4 — Data Structures | Real school data stored and queryable |
| Unit 5 — APIs & Web Data | Gemini AI integration — the bot gets smart |
| Final Push | ML features, data visualization, and making it production ready |
